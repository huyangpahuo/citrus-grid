本文覆盖 `src/components/` 下全部 17 个 Astro 组件（`src/components/` 10 个通用组件 + `src/components/pages/` 7 个页面级组件）与 1 个布局。

> 组件分层约定
> 项目把组件分成两层，理解这一点能省很多力气：
>
> - 页面级组件 `src/components/pages/*.astro`：承载某个页面的完整内容（标题区、列表、空状态），只接收数据 props；
> - 路由文件： `src/pages/*.astro`：只做「取数据 → 传给页面组件 → 包一层 BaseLayout」的薄封装。
>
> 所以「改页面长相」去 `components/pages/`，「改 URL 或取数逻辑」去 `src/pages/`。

## 2. 基础原子组件

### 2.1 `Icon.astro`

```astro
<Icon d={mdiCalendarOutline} class="text-sm" />
```

| Prop | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `d` | `string` | 是 | — | SVG `<path>` 的 `d` 属性，来自 `src/lib/icons.ts` 的导出常量 |
| `class` | `string` | 否 | — | 追加到根 `<svg>`，会与 `mdi-icon` 类合并 |

输出结构：

```html
<svg class="mdi-icon text-sm" width="1em" height="1em" viewBox="0 0 24 24"
     fill="currentColor" aria-hidden="true"><path d="…"></path></svg>
```

要点：

- 尺寸用 `1em`，所以通过字体大小 class 控制图标大小（`text-sm` / `text-lg` / `text-[11px]`）；
- 颜色继承 `currentColor`，跟随文字色；
- 固定 `aria-hidden="true"`，装饰性图标不进无障碍树。需要语义时请在父元素上写 `aria-label`（如 `ScrollControls` 的 `title`）。

### 2.2 客户端字符串版本 `iconSvg()`

有些地方需要在构建期拼 HTML 字符串（代码块头部、复制按钮），不能渲染组件，于是 `src/lib/icons.ts` 提供了同名函数：

```ts
import { iconSvg, type IconName } from '@/lib/icons'
iconSvg('mdi-content-copy')          // → '<svg class="mdi-icon" …></svg>'
iconSvg('mdi-check', 'text-green')   // 第二参数追加 class
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `name` | `IconName` | `icons` 映射表的 key，kebab-case 全名 |
| `cls` | `string` | 追加 class，默认 `''` |

### 3.2 `SiteFooter.astro`

| Prop | 类型 | 默认 |
| --- | --- | --- |
| `lang` | `Lang` | `defaultLang` |

构建期取最早一篇文章的发布时间，运行时长（天/时/分/秒）由客户端脚本每秒实时计算：

```ts
// 构建期：只确定起点，并把初始时长写进页面作为无 JS 的回退显示
const publishedPosts = await getPublishedPosts()
const earliest = publishedPosts.reduce<Date|null>((min, p) =>
  min === null || p.data.published < min ? p.data.published : min, null)
function breakdown(ms: number) {
  const total = Math.max(0, Math.floor(ms / 1000))
  return {
    days: Math.floor(total / 86400),
    hours: Math.floor((total % 86400) / 3600),
    minutes: Math.floor((total % 3600) / 60),
    seconds: total % 60,
  }
}
const buildUnits = earliest ? breakdown(Date.now() - earliest.valueOf()) : null
```

```ts
// 客户端：当前时间与最早文章时间的差值实时计算，精确到秒（<script> in SiteFooter.astro）
function breakdown(ms: number) {
  const total = Math.max(0, Math.floor(ms / 1000))
  return {
    days: Math.floor(total / 86400),
    hours: Math.floor((total % 86400) / 3600),
    minutes: Math.floor((total % 3600) / 60),
    seconds: total % 60,
  }
}
function updateRunningTime() {
  document.querySelectorAll<HTMLElement>('[data-running-days]').forEach((el) => {
    const iso = el.dataset.earliest
    const template = el.dataset.template
    if (!iso || !template) return
    const u = breakdown(Date.now() - new Date(iso).getTime())
    const text = template
      .replaceAll('{days}', String(u.days))
      .replaceAll('{hours}', String(u.hours))
      .replaceAll('{minutes}', String(u.minutes))
      .replaceAll('{seconds}', String(u.seconds))
    if (el.textContent !== text) el.textContent = text
  })
}
updateRunningTime()
document.addEventListener('astro:page-load', updateRunningTime)
// 每秒刷新，秒位实时跳动；重复执行时只挂一个定时器
if (!('__runningTimeTimer' in window)) {
  ;(window as any).__runningTimeTimer = setInterval(updateRunningTime, 1000)
}
```

| 显示项 | 条件 | 文案 key | 备注 |
| --- | --- | --- | --- |
| `© {year} {author} All rights reserved` | 总是 | — | 年份取构建时的 `new Date().getFullYear()`，作者链接指向 `siteConfig.url` |
| `Powered by Astro & CitrusGrid` | 总是 | — | 纯静态文本 |
| RSS / Sitemap 链接 | 总是 | `footer.rss` / `footer.sitemap` | RSS 走 `localePath(lang, '/rss.xml')`；Sitemap 硬编码 `/sitemap-index.xml` |
| 运行时长（天/时/分/秒） | `earliest` 存在（即至少有一篇文章） | `footer.running`（`{days}` `{hours}` `{minutes}` `{seconds}` 占位） | 无文章时不显示 |

> 运行时长的实现细节：
>
> - `<p data-running-days>` 上挂 `data-earliest`（ISO 时间，构建期写入）和 `data-template`（当前语言的 `footer.running` 文案），服务端先渲染构建期算好的初始值。
> - 完全实时，不受构建固定：首次加载、Swup 换页（`astro:page-load`）、以及每秒的定时器都会用客户端当前时间与最早文章时间的差值重算四个单位；仅文本变化时写 DOM，避免无谓重排。页面一直开着，秒位也会实时跳动并自动进位。
> - 语义为"经过的时长"（毫秒差拆分为天/时/分/秒），时区无关。

| Prop | 类型 | 默认 |

| 选择器 | 作用 |

| `#search-results` | 结果容器（`hidden` / `flex` 切换） |

行为参数（源码内常量，可直接调）：

| 常量 | 值 | 位置 | 作用 |
| --- | --- | --- | --- |
| `pagefindUrl` | `'/pagefind/pagefind.js'` | `loadPagefind()` | 索引路径，与 `postbuild.js` 中 `pagefind --site dist` 的输出目录对应 |
| 结果条数上限 | `20` | `res.results.slice(0, 20)` | 防止一次渲染过多 DOM |
| 子结果条数上限 | `3`（`MAX_SUB_RESULTS`） | `renderSubResults()` | 单篇文章最多展示 3 个命中章节，超出显示「本文还有 N 处命中」 |
| 打开事件 | `document` 上的 `open-search` 自定义事件 | `document.addEventListener('open-search', open)` | 由 `ScrollControls` 的搜索按钮派发 |
| 关闭时机 | `Escape` / 点遮罩 / 点 `#search-close` 走 `close()`；`astro:after-swap` 与点结果跳转走 `close(false)` | — | 动画：遮罩 `wp-fade-out` + 面板 `wp-pop-out`，0.16s 淡出后置 `hidden`；`prefers-reduced-motion` 或跳转时瞬时关闭；关闭途中重新打开会取消定时器防闪烁 |
| 跳转方式 | 带锚点时接入跨页锚点机制（hash 记到 `window.__pendingScrollHash`，`swup.navigate()` 用去掉 hash 的 URL，加载后平滑滚动）；同页带锚点直接调用 `window.__scrollToHeadingAnchor` 平滑滚动，不刷新页面；无锚点 / 无 swup 时退化为 `location.assign` | `go()` | 搜索结果（含章节级子结果）能精确滚动到命中位置，见 [07-页面与路由.md#84](./07-页面与路由.md#84-跨页锚点链接的平滑跳转) |

搜索结果渲染的字段（与 Pagefind 返回结构对应）：

```ts
item.url              // 结果链接（页面级，无 hash）
item.meta?.title      // 标题（缺省回退到 url）
item.excerpt          // 页面级摘要（Pagefind 自带高亮 <mark>），仅在没有子结果时兜底显示
item.sub_results      // 章节级子结果：按带 id 的 h1~h6 拆分页面，命中多的章节优先
//   sub.url         // 形如 /posts/xxx/#章节id（中文锚点已百分号编码）
//   sub.title       // 章节标题（首个无锚点子结果是页面本身，渲染时跳过）
//   sub.excerpt     // 该章节内的高亮摘录
//   sub.anchor      // { element, id, text, location }，用于去重与回退取标题
```

> `excerpt` 是 Pagefind 生成的 HTML，未经 `escapeHtml`，这是有意为之（保留高亮 `<mark>`，用 `[&_mark]:` 任意属性选择器上主题色）；`url` 与 `title` 走了 `escapeHtml`。

> 结果卡片结构：文章标题（点击进文章顶部）→ 分隔线 → 命中章节列表（最多 `MAX_SUB_RESULTS` 条，点击滚动到对应标题）。文章无带 id 的标题时退化为「标题 + 页面级摘录」。

### 3.4 `ScrollControls.astro`

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `lang` | `Lang` | `defaultLang` | 取词 |
| `showTocButton` | `boolean` | `false` | 是否渲染目录按钮（仅文章页传 `true`） |

右侧整合菜单：底部一个常驻「菜单」触发器（`data-scroll-menu`，汉堡图标，只负责展开/收起），点击后其余按钮从触发器左侧横向弹出（在 `.scroll-control-nav` 上加 `.is-open`）；从左到右：目录 → 主题 → 搜索 → 回顶（回顶最靠近触发器）。滚动、点击外部、按 `Esc` 或换页（`astro:before-swap`）都会自动收起。

弹层内按钮（从左到右，回顶最靠近触发器）：

| 按钮 | 关键属性 | 触发方式 | 备注 |
| --- | --- | --- | --- |
| 回顶 | `data-backtop` | `BaseLayout` 委托点击 → `window.scrollTo({behavior:'smooth'})` | 常驻显示，无滚动显隐判断 |
| 搜索 | `data-open-search` | `BaseLayout` 委托点击 → 派发 `open-search` | — |
| 主题 | `data-theme-toggle` | `stores/theme.ts` 的全局委托点击 | 图标由 `syncThemeButtons()` 动态替换（日/月） |
| 目录 | `id="toc-fab"`，`hidden={!showTocButton}` | `PostPage.astro` 里绑定 `click` → `openTocModal()` | `ScrollControls.css` 中 `@media (min-width: 1280px) { .toc-btn { display: none } }`：桌面端隐藏，因为桌面上用 `xl:block` 的侧边固定目录 |

定位：触发器 `fixed right-5 bottom-8 z-[90] max-md:right-3 max-md:bottom-16`，弹出层用绝对定位锚定在其左侧（`right: calc(100% + 8px); bottom: 0`），横向排开。启用音乐播放器时，音乐 FAB 由 `MusicPlayer.reposition()` 固定在右下底部槽位（桌面 32 / 移动 64），菜单触发器随之挪到音乐按钮正上方（原搜索位置）。

桌面侧边目录（`#toc-affix`，仅 `xl` 且有目录时出现）自带收起/展开：标题行右侧的 `#toc-collapse` 按钮把面板淡出，同时在右下菜单触发按钮正上方浮出 `#toc-expand` FAB（复用 `scroll-control-btn` 样式；位置由 `PostPage` 的 `positionTocExpandFab()` 读取 `[data-scroll-menu]` 矩形实时计算，音乐按钮启用时菜单上移、FAB 跟随，音乐仍保持最底；菜单弹层向左弹出后不占用该位置，菜单展开时 FAB 无需隐藏）。收起状态存于模块变量 `tocCollapsed`，换文章页时由 `initPage()` 重新应用（跨文章保持）。移动端（`<xl`）不渲染该控件，仍走 `toc-fab` 弹窗目录。

> ⚠️ `hidden` 属性必须靠 CSS 显式覆盖。`ScrollControls.css` 里有 `.scroll-control-btn[hidden] { display: none }`，因为 `display: inline-flex` 优先级高于 `hidden` 属性的默认样式。自定义按钮时别丢这条规则。

### 4.11 `MusicPlayer.astro`

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `lang` | `Lang` | `defaultLang` | 取 UI 文案 |

播放列表来源（两级优先）：

| 优先级 | 条件 | 行为 |
| --- | --- | --- |
| 1 | `siteConfig.musicPlayer.playlist.length > 0` | 直接用配置的列表（可自定义 `title` / `cover` / 顺序） |
| 2 | 配置为空数组 | 构建期扫描 `public/music/`，按文件名 `localeCompare(a, b, 'zh')` 排序生成列表 |

```text
# 已验证
.flac  .mp3

# 未验证
.m4a  .ogg  .wav  .opus  .aac  .webm
```

| --- | --- |
| `[data-music-player]` | 播放器根 `<section>` |
| `[data-music-open]` | 右下角磁铁悬浮按钮 |
| `[data-music-audio]` | `<audio preload="metadata" playsinline>` |
| `[data-music-cover]` / `[data-music-cover-wrap]` | 封面图与容器 |
| `[data-music-list]` | 播放列表面板 |
| `[data-music-showlist]` | 展开播放列表按钮 |

注入给客户端的配置：

```html
<script is:inline define:vars={{ playlist, ui }}>
  window.__musicPlayerConfig = { playlist }   // 曲目列表
  window.__musicPlayerUI = ui                 // 控件文案（来自 i18n 的 player.* 词条）
</script>
```

| 全局变量 | 注入内容 | 客户端用途 |
| --- | --- | --- |

## 4A. 图标系统（`src/lib/icons.ts`）

全站图标硬编码在 `src/lib/icons.ts`：66 个 `export const mdiXxx = '<path d>'` 常量，加一个 `icons` 映射表（kebab-case 名 → path）与两个导出。

设计取向（源码注释 + `添加自定义图标.md`）：零网络请求、零依赖，代价是加图标要手写三步。

### 4A.1 三个导出

| 导出 | 类型 | 用途 |
| --- | --- | --- |
| `mdiXxx` | `string`（SVG path 的 `d`） | 组件里按名 import 后传给 `<Icon d={…} />` |
| `icons` | `as const` 对象 | kebab-case 全名 → path，供字符串场景使用 |
| `IconName` | `keyof typeof icons` | 类型约束（`iconSvg()` 的入参类型） |
| `iconSvg(name, cls?)` | `(IconName, string) => string` | 构建期拼 HTML 字符串（代码块头部、复制按钮用） |

```ts
export function iconSvg(name: IconName, cls = ''): string {
  return `<svg class="mdi-icon${cls ? ` ${cls}` : ''}" width="1em" height="1em" viewBox="0 0 24 24" fill="currentColor" aria-hidden="true"><path d="${icons[name]}"></path></svg>`
}
```

### 4A.2 添加图标的三个步骤

第 1 步：在 [MDI 图标库](https://pictogrammers.com/library/mdi/) 复制 SVG path，按字母序粘贴到 `src/lib/icons.ts` 顶部：

```ts
export const mdiAbTesting = 'M4 2A2 2 0 0 0 2 4V12H4V8H6V12H8V4…'
```

第 2 步：在文件底部的 `icons` 映射表加条目（key 必须是 kebab-case 全名，与常量名对应）：

```ts
export const icons = {
  // ...
  'mdi-ab-testing': mdiAbTesting,
} as const
```

第 3 步：在组件里使用

```astro
---
import Icon from '@/components/Icon.astro'
import { mdiAbTesting } from '@/lib/icons'
---

<Icon d={mdiAbTesting} class="text-sm" />
```

或在构建期拼字符串：`iconSvg('mdi-ab-testing')`。

> 漏掉第 2 步会类型报错
>
> `IconName = keyof typeof icons`，只加常量不加映射时，`iconSvg('mdi-ab-testing')` 会 TS 报错。

### 5.4 防闪烁主题脚本（`<head>` 内联）

```js
var stored = localStorage.getItem('themeMode')
var mode = (stored === 'light' || stored === 'dark') ? stored : defaultTheme
if (mode !== 'light' && mode !== 'dark') {                 // 即 defaultTheme === 'auto'
  mode = window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'
}
document.documentElement.classList.toggle('dark', mode === 'dark')
document.documentElement.style.colorScheme = mode
```

> 这段脚本必须在 `<head>` 同步执行，否则会出现「先白后黑」闪烁。改主题逻辑时不要把它改成 module 或挪到 `<body>` 末尾。

### 5.5 `#swup-container` 外的脚本职责（`BaseLayout` 底部 `<script>`）

| 函数 / 监听 | 作用 |
| --- | --- |
| `initTheme()` | 初始化主题（来自 `stores/theme.ts`） |
| `syncTocFab()` | 依据当前页是否存在 `#toc-affix` 决定右下目录按钮显隐；在 `astro:after-swap` 与 `astro:page-load` 两个时机各同步一次，避免竞态 |
| `syncNavState(path?)` | 遍历 `a[data-nav-path]`，用 `text-accent` / `text-ink-2` 切换高亮；处理 `__fallback__`；关闭 `header details[open]` |
| `bindNavStartSync()` | 绑定 Swup 的 `visit:start` 钩子，让导航高亮在跳转开始就更新（最多重试 100 次 × 100ms，等待 `window.swup` 就绪） |
| `astro:before-swap` | 移除容器外残留的 `#toc-affix`（重新 append 到 body），并同步导航状态 |
| 点击委托 | `[data-scroll-menu]` 切换整合菜单展开/收起；`[data-backtop]` 平滑回顶；`[data-open-search]` 派发 `open-search`；`details.md-container-details` 的 `summary` 点击时播放折叠动画（用 Web Animations API 从 `scrollHeight` 动画到 0，然后移除 `open`） |
| 跨页锚点点击委托 | 拦截「同源 + 带 `#` + 跨路径」的内部链接：锚点记到 `window.__pendingScrollHash`，`swup.navigate()` 用去掉 hash 的 URL 导航到页顶（无 swup 时回退 `location.assign`）；修饰键、非左键、`data-no-swup`、外站链接放行 |
| `consumePendingScrollHash()` | `astro:page-load` 时消费待滚动锚点：hash 写回地址栏，120ms 后 `smoothScrollToHeadingAnchor()` 平滑滚动（80px 偏移，同目录；`prefers-reduced-motion` 降级为瞬时） |
| `window.__scrollToHeadingAnchor` | `smoothScrollToHeadingAnchor()` 的全局暴露，供 `SearchModal` 的同页锚点跳转复用 |

跨页锚点（`/posts/xxx#slug`）的平滑滚动由上述「跨页锚点点击委托」+ `consumePendingScrollHash()` 实现；配合 `<head>` 里一段内联「去 hash」脚本，直接打开收藏/分享的 `#` 深链接同样不闪现。完整流程见 [07-页面与路由.md#84](./07-页面与路由.md#84-跨页锚点链接的平滑跳转)。

## 6. 全局事件与 data 属性协议速查

改组件或加组件时，沿用这些约定就能自动接入现有交互：

### 6.1 自定义事件

| 事件 | 派发者 | 监听者 | 用途 |
| --- | --- | --- | --- |
| `open-search` | `BaseLayout`（点击 `[data-open-search]`） | `SearchModal` | 打开搜索弹窗 |
| `theme-change` | `stores/theme.ts` 的 `applyTheme()`，`detail` 为 `'light' \| 'dark'` | `comments/client.ts`（转发给适配器 `onThemeChange`） | 主题切换通知 |
| `astro:page-load` | Astro / BaseLayout 补发 | `lib/pageLifecycle.ts` 的 `onPageLoad`、多处初始化 | 页面（含 Swup 换页）就绪 |
| `astro:after-swap` | Swup / Astro | TOC 按钮显隐同步（`BaseLayout`）、主题重应用（`theme.ts`）、关闭搜索弹窗（`SearchModal`）。注意：目录弹窗 `#toc-modal` 无人监听此事件 | DOM 已替换 |
| `astro:before-swap` | Swup / Astro | 移除容器外残留的 `#toc-affix`（只 remove，append 由 `PostPage` 的 `initPage()` 负责）、重置导航状态、卸载评论适配器 | DOM 即将替换 |

> 新增常驻脚本的正确姿势：
>
> 在 `.astro` 里写 `<script>`，并用 `onPageLoad()` 包裹初始化：
>
> ```ts
> import { onPageLoad } from '@/lib/pageLifecycle'
> function initMyWidget() { /* 幂等初始化 */ }
> onPageLoad(initMyWidget)
> ```
>
> `onPageLoad` 会同时监听 `astro:page-load` 并在「本次加载已经触发过」时立即执行，避免 Swup 换页后脚本不跑。
